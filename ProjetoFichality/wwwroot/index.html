SOBRE O PROJETO

Mais liberdade para jogar.

O Fichality é uma plataforma em desenvolvimento para criar, personalizar e gerenciar fichas de personagens de RPG. A proposta é permitir que diferentes sistemas convivam em uma experiência flexível e fácil de adaptar.

Estrutura flexível

Campos e blocos adaptáveis a diferentes estilos de jogo.

Persistência híbrida

Dados relacionais para as entidades principais e JSON para estruturas variáveis das fichas.

Biblioteca em evolução

Uma base para sistemas, modelos, equipamentos e campanhas que será ampliada por etapas.
